# Admin guide

The full, illustrated guide is **inside the application**: sign in as admin and open **Help & guide** in the sidebar
(`/admin/help`). Each admin page also has a "Guide for this page" link, and the **Overview** page shows a live
setup checklist.

Candidates have their own guide at `/help` (linked from their dashboard and the rules page).

## One-paragraph summary
Onboard colleges -> create a test per stage in the Test Center (MCQ / Likert / Coding) -> add or upload questions (previewed
before saving) -> review and publish -> add candidates (single or CSV) -> assign by batch -> monitor (outcome tiles, filters,
proctoring log) -> review the Integrity tab -> export results. Questions lock once anyone starts a test; duplicate the test to
change them. Deleting tests or candidates is permanent and audited.
